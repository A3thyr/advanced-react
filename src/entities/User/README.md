## Сущность пользователя

Описание:
содержит данные авторизованного пользователя, роли и инфраструктуру для инициализации пользовательского состояния в приложении.

#### Public api

- store

`userReducer` - редьюсер сущности пользователя

`userActions` - actions для обновления пользовательского состояния

- types

`User` - тип пользователя

`UserSchema` - тип состояния пользователя в сторе

`UserRole` - enum ролей пользователя

- selectors

`getUserAuthData` - селектор данных авторизованного пользователя

`getUserInited` - селектор флага инициализации пользователя

`getUserRoles` - селектор списка ролей пользователя

`isUserAdmin` - селектор проверки роли администратора

`isUserManager` - селектор проверки роли менеджера
