## Сущность счетчика

Описание:
демонстрационная сущность с простым числовым состоянием, компонентом отображения и набором селекторов.

#### Public api

- Components

`Counter` - компонент счётчика

- store

`counterReducer` - редьюсер счётчика

`counterActions` - actions для изменения значения счётчика

`counterSlice` - slice счётчика

- types

`CounterSchema` - тип состояния счётчика в сторе

- selectors

`getCounter` - селектор всего состояния счётчика

`getCounterValue` - селектор текущего числового значения счётчика
